# Antigravity AI Skills Collection

Kho lưu trữ toàn bộ các Kỹ Năng (Custom Skills) tùy chỉnh cho Antigravity AI Agent.

## 📦 Danh Sách Các Skills Đã Được Đóng Gói (6 Skills):

1. **`analyze-video`**: Phân tích video short-form (Reels, TikTok, Shorts, Carousel album), bóc tách điểm cắt cảnh OpenCV, trích xuất Keyframes (Start-Mid-End), xuất báo cáo PDF chuẩn Chrome Headless (không lỗi font tiếng Việt) và tự động đồng bộ trọn bộ dự án lên Google Drive (`Work/AI_Video_Analysis`).
2. **`create-landing-page`**: Tự động nhân bản & tạo Landing Page bán hàng chuyên nghiệp tích hợp thanh toán tự động VietQR + SePay.
3. **`sua-phu-de-capcut`**: Tự động đọc và sửa phụ đề tiếng Việt trong project CapCut desktop.
4. **`nhan-ban-web`**: Kỹ năng sao chép, trích xuất cấu trúc và nhân bản giao diện website.
5. **`vietmac-voice`**: Kỹ năng viết bài chuẩn giọng văn thương hiệu cá nhân VietMac (ngắn gọn, cuốn hút, chuyển đổi cao).
6. **`miss-sale-page`**: Kỹ năng thiết kế trang bán hàng phong cách hiện đại, tối ưu tỷ lệ chuyển đổi.

## 🚀 Hướng Dẫn Cài Đặt / Khôi Phục:
Copy các thư mục trong thư mục `skills/` vào một trong các vị trí sau:
- Thư mục dự án: `<workspace>/.agents/skills/`
- Thư mục toàn cục: `C:\Users\<User>\.gemini\config\skills/` (Windows) hoặc `~/.gemini/config/skills/` (macOS)
