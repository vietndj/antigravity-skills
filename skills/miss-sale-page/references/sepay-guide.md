# Hướng dẫn đăng ký SePay & Lấy API Key

1. Truy cập https://my.sepay.vn và đăng ký tài khoản
2. Liên kết tài khoản ngân hàng (MB Bank, TPBank, Vietcombank...)
3. Vào Cài đặt → API Key → Tạo API Key mới
4. Copy API Key và nhập vào khi được hỏi
5. (Tùy chọn) Cấu hình Webhook URL: `https://<your-domain>/api/payment/webhook`
